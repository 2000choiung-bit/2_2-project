# 📝 [Troubleshooting] 전신사진 실측 비례식 API 및 상·하의 사이즈 추천 알고리즘 고도화

## 1. 개요 (Overview)
* **작업 내용:** 프론트엔드 가이드 프레임 기준($700\text{px}$) 전신사진 비례식 실측 API 구현, 상·하의 카테고리별 사이즈 추천 엔진 고도화, JWT 인증 바인딩 오류 해결[cite: 10, 12, 13]
* **관련 기술:** Spring Boot, Spring Security(JWT), JPA/Hibernate, MultipartFile, Swagger UI[cite: 5, 10, 15]

---

## 2. 발생한 문제 및 해결 과정 (Trouble Shooting)

### 🔴 문제 1: 사이즈 추천 API에서 하의(바지) 카테고리 추천 불가 및 여유분 미반영
* **원인:** 기존 `SizeRecommendationService`가 상의 기준(`shoulderWidth`, `chestWidth`)으로만 오차를 계산하도록 작성되어 있어, 하의 상품(와이드 데님 팬츠 등) 조회 시 오차가 `0`으로 처리되어 무조건 첫 번째 사이즈만 추천되는 버그가 있었음[cite: 12]. 또한 신체 치수와 옷 실측 치수 간 의류 기본 여유분(Ease)이 반영되지 않았음.
* **해결:** 
  * 상품의 `category`가 `"하의"`일 경우 `waistWidth`(허리단면)와 `hipWidth`(엉덩이단면)를 비교하도록 분기 로직을 분리함[cite: 12].
  * 상의/아우터/하의 각각의 표준 의류 여유분(`easeAllowance`)을 반영하여 현실적인 핏 점수(`fitScore`)와 여유분 요약(`fitDiffSummary`)을 반환하도록 고도화함[cite: 12, 13].
* **느낀점:** 추천 알고리즘을 설계할 때는 상품군(상의/하의/아우터)에 따른 핵심 측정 부위의 차이와 실제 착용 시 필요한 여유분을 도메인 로직에 명확히 녹여내야 함을 배웠다.

### 🔴 문제 2: JWT 기반 추천 API 호출 시 `500 Internal Server Error` (`NullPointerException`)
* **원인:** `SizeRecommendationController`에서 로그인 유저 정보를 꺼낼 때 `@AuthenticationPrincipal UserDetails userDetails`로 바인딩했으나, 프로젝트의 `JwtAuthenticationFilter`는 `SecurityContext`에 `UserDetails` 객체가 아닌 `String username`을 Principal로 저장하고 있어 `userDetails`가 `null`로 주입됨[cite: 9].
* **해결:** 컨트롤러 파라미터를 `@AuthenticationPrincipal String username`으로 수정하여 토큰에서 추출된 사용자 아이디를 서비스 계층으로 정상 전달함.
* **느낀점:** 팀 프로젝트에서 공통 보안 필터(`JwtAuthenticationFilter`)가 `Authentication` 객체에 어떤 타입의 Principal을 적재하는지 정확히 확인하고 컨트롤러 어노테이션 타입을 일치시켜야 런타임 NPE를 방지할 수 있다.

## 3. 주요 구현 내용 및 검증 결과
* **전신사진 비례식 실측 API (`POST /api/profiles/photo-measurement`)**[cite: 5]
  * 프론트엔드 실루엣 오버레이 프레임 세로 기준($700\text{px}$) 대비 사용자 실제 키($\text{cm}$) 비례식($\text{Scale} = \frac{\text{키}}{700\text{px}}$) 적용[cite: 5].
  * 2차 정밀 실측 데이터(`shoulder`, `chest`, `waist`, `hip`) DB 저장 및 `hasBodyProfile: true` 상태 전환 검증 완료[cite: 5].
* **2단계 AI 사이즈 추천 API (`GET /api/recommendations/{productId}`)**[cite: 12, 13]
  * 1차 기본 신체 추정 모드(`isCustomMeasured: false`) 및 2차 사진 실측 모드(`isCustomMeasured: true`) 자동 전환 검증[cite: 12, 13].
  * 상의(`productId: 1`) 및 하의(`productId: 4`) 모두 `200 OK` 정상 응답 확인[cite: 12, 13].
